# RepurposeAI

An automated content repurposing pipeline that converts YouTube videos and web articles into optimized social posts for Twitter, LinkedIn, and newsletters.

## Features

- **Multi-Source Extraction:** Extract transcripts from YouTube videos and content from web articles.
- **AI Automation:** Generate platform-specific social posts (Twitter threads, LinkedIn articles, Newsletter summaries) using Gemini API.
- **Kanban Workflow:** Review, edit, and organize generated drafts before publishing.
- **1-Click Export:** Copy formatted text directly to your clipboard.

## Tech Stack

- **Frontend:** Next.js (React), Tailwind CSS, shadcn/ui
- **Backend:** FastAPI (Python)
- **Database & Auth:** Supabase (PostgreSQL)
- **AI Engine:** Google Gemini API
